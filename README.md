# CryptoGraph

**Interactive cryptography laboratory | Python · FastAPI · RSA · SHA-256 · JavaScript**

[![Python 3.12+](https://img.shields.io/badge/Python-3.12%2B-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![FastAPI](https://img.shields.io/badge/API-FastAPI-009688?logo=fastapi&logoColor=white)](https://fastapi.tiangolo.com/)

> **Educational project, not a secure vault or production key-management service.** Data you enter, including private PEM keys during signing or decryption, is sent to the API server. Never submit real private keys, credentials or confidential files to a hosted demo.

CryptoGraph is a web-based learning tool for comparing historical ciphers with modern hashing, public-key encryption and digital signatures. Built for university **Security & Cryptography** and **Web Services and Design** coursework, it includes an independently accessible REST API, custom browser UI, Docker support and Python tests.

![CryptoGraph hero illustration](static/images/cryptograph-hero.png)

**Reviewer shortcut:** [5-minute walkthrough](docs/REVIEWER_GUIDE.md) · [API endpoints](docs/API.md) · [Architecture](docs/ARCHITECTURE.md) · [Security model](SECURITY.md)

## Engineering overview

| Area | Implementation |
| --- | --- |
| API | FastAPI routers, Pydantic request models and autogenerated OpenAPI at `/docs` |
| Historical ciphers | Caesar (shift/custom alphabet), Vigenère (keyword validation) |
| Modern primitives | SHA-256, RSA-OAEP encryption and RSA-PSS signatures via the `cryptography` package |
| File operations | Hash, sign and verify with a 10 MiB application upload limit |
| Frontend | Responsive HTML/CSS/vanilla JavaScript using HTTP API endpoints |
| Testing and delivery | pytest unit/API tests, GitHub Actions, Dockerfile and Render blueprint |

**Key safety:** Caesar and Vigenère are intentionally insecure teaching examples. RSA keys are 2048–4096 bits, with disposable test keys recommended. The application does not offer end-to-end or zero-knowledge encryption.

## Quick start

Requires **Python 3.12+**. No database, cloud account or environment secrets are needed for local development.

```bash
git clone https://github.com/GotsadzeLuka/CryptoGraph.git
cd CryptoGraph
python -m venv .venv
source .venv/bin/activate            # macOS / Linux
# .venv\Scripts\Activate.ps1         # Windows PowerShell
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Then visit:
- **Web interface:** http://localhost:8000
- **Swagger API docs:** http://localhost:8000/docs
- **Health endpoint:** http://localhost:8000/health

### Example API requests

```bash
curl http://localhost:8000/health

curl -X POST http://localhost:8000/api/classical/caesar/encrypt \
  -H "Content-Type: application/json" \
  -d '{"text":"abc","shift":3}'

curl -X POST http://localhost:8000/api/modern/hash/sha256 \
  -H "Content-Type: application/json" \
  -d '{"text":"hello"}'

curl -X POST http://localhost:8000/api/files/hash \
  -F "file=@sample_data/LukaGotsadze.txt"
```

For all 14 documented API endpoints and request fields, see the **[API reference](docs/API.md)**.

## Tests and quality checks

```bash
python -m pytest -v tests/
python -m compileall -q app main.py
python -m pip check
```

The tests cover cipher round trips, RSA key operations, signatures, hashing and FastAPI endpoint behavior, including invalid inputs and resource limits. The [CI workflow](.github/workflows/ci.yml) runs across Python 3.12 and 3.13. **Consult GitHub Actions for actual execution status; the presence of CI configuration alone does not mean tests pass.**

## Architecture

```text
Browser (HTML/CSS/JS)          HTTP API clients
            \                  /
             FastAPI routes and Pydantic
                /          \
      Caesar / Vigenère    SHA-256 / RSA
                \          /
              JSON responses
```

- `main.py` — FastAPI application and static asset mounting
- `app/api/` — Request schemas, response schemas and HTTP routes
- `app/classical/` — Caesar/Vigenère algorithm implementations
- `app/modern/` — SHA-256 hashing, RSA encryption and signatures
- `app/services/` — Reusable facade for cryptographic operations
- `app/utils/` — Input handling helpers
- `static/` — Browser frontend and visual assets
- `tests/` — Algorithm unit tests and API integration tests

See the [architecture documentation](docs/ARCHITECTURE.md) for data flow and trust boundaries.

## Docker and deployment

```bash
docker build -t cryptograph .
docker run --rm -p 8000:8000 cryptograph
```

**Hosted demo status: offline.** The former Vercel deployment is no longer available. Reviewers should run CryptoGraph locally using the Quick Start or Docker instructions above; there is no active public demo URL. `render.yaml` is retained only as an optional deployment configuration example. The unauthenticated API requires additional hardening before any public production use.
